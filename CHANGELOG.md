# Changelog

All notable changes to this repository are documented here. Dates are UTC.

## [dev-stage2-gaussianzoom] - 2026-09-15

GaussianZoom-inspired Stage 2 cutover. This branch replaces the previous
FlowEdit/Difix3D-based IDU synthesis on the original Skyfall-GS Stage 1 +
native training-view pipeline with a new synthesis stage. It is **not** a
paper-complete GaussianZoom replication, and **no** image-quality improvement
is claimed by these changes.

### Stage 2 synthesis (GaussianZoom-inspired cutover)

- **Qwen3-VL per-view prompts**: every target view gets its own structured
  prompt generated by local Qwen3-VL, cached per episode/view; all samples of a
  view share one prompt. Prompts summarize short, distinct feature categories
  instead of enumerating every building so crowded-view JSON answers stay
  within the VLM output budget.
- **DLoRAL geometric/multiview refinement**: each rendered target view is
  refined with geometry-guided DLoRAL using depth/alpha-valid reprojection
  coverage from same-episode neighbor views. Views below
  `--idu_min_reprojection_coverage` fall back to explicit `target_only`
  refinement (recorded in episode metadata); no view is left as the unchanged
  RGB render.
- **Persistent generation workers**: Qwen3-VL and DLoRAL run in dedicated
  isolated environments (`VLM_PYTHON`, `VLM_MODEL_PATH`, `DLORAL_PYTHON`,
  `DLORAL_WEIGHT_ROOT`) as subprocesses that never run inside the training
  process. One Qwen load serves all prompts of an episode, then one DLoRAL
  worker serves all samples; both exit before MoGe/3DGS optimization starts.
  Cache-only phases start no workers.
- **Twelve-scene queues**: `scripts/train_full_dataset.py` runs all eight JAX
  and four NYC scenes (JAX 3x3 IDU grid, NYC 4x4 grid; Stage 1 at 30k
  iterations plus five 10k-iteration Stage 2 episodes per scene), with
  single-scene retry (`--retry-failed --wait-lock`). The runner is a frozen
  experiment queue: its scene table, recipes and root/reuse defaults target
  the 2026-09-13 experiment; the shared pipeline manifest is cross-checked,
  not a generic launcher configuration, and fresh deployments must override
  the run/control/archive roots (see README "Pipeline Manifest").
- **Gated compact retention**: `--compact_retention` keeps final models,
  metrics, prompt/camera provenance and representative comparisons while
  removing consumed dense generation scratch and superseded Stage 2 model
  pairs — only after the newer artifacts are safely retained. Intermediate
  episodes require replaying earlier training to recreate.
- **SHA-bound archive + local eval**: `scripts/archive_dataset_results.py`
  freezes a selected file manifest, rsyncs, verifies SHA256 on both ends, and
  publishes `archive_status.json`; remote finals are deleted only after local
  SHA256 verification **and** a local evaluation that confirmed the model
  actually loads (`model_load_verified: true`). Retention keeps **both** the
  final checkpoint (learned appearance embeddings/MLP) and the matching PLY
  (`filter_3D`).
- **MoGe sparse/empty support repair** (`patches/moge-sparse-depth.patch`,
  applied to the pinned MoGe submodule after clone): recovers sparse valid
  pixels missed by the 64x64 solver sampling; a genuinely empty prediction
  stays undefined and contributes no pseudo-depth loss instead of crashing
  SciPy or inventing a depth estimate. The pinned submodule commit is
  unchanged; the dirty worktree is exactly the applied patch.
- **Six-scene 84-second comparison video tool**: `scripts/local_scene_comparison.py`
  + `scripts/compose_scene_comparison_video.py` render fresh CUDA orbits from
  the local archive and compose one labelled 1920x1080 H.264 video (six scenes
  with both stages complete, 84 s total). JAX_264 (Stage 1 only) is excluded;
  JAX_168/175 use internal Stage1/Stage2 comparisons because official released
  references exist only for JAX_004/068/214/260.
- TensorBoard logging keeps full-resolution pixels and metrics but uses fast
  lossless PNG encoding with native `crc32c`; depth previews are computed only
  when they will be logged.

### Scope and non-claims

- Current run status (this experiment, 2026-09-13 archive): 13 complete stage
  archives, 9 formal full evaluations, and supplementary heldout/video
  inference for all 13 archives — **not** a complete 24/24 (12 scenes x 2
  stages) set.
- No focal-length zoom is used in Stage 2 (resolution/upscale/`zoom_factor`
  stay 1); the GaussianZoom-derived synthesis is an inspiration, not a
  replication, and no quality improvement is claimed.
- Not all 12 scenes have formal full evaluations: supplementary heldout and
  video inference exist for all completed stage archives, but formal full
  evals cover a subset. Evaluation GT pairing has known limitations:
  official external comparisons cover JAX_004/068/214/260; camera-unverified
  GT pairing is disabled by default. The formal metrics protocol is the
  default fixed appearance row `min(6, n_train - 1)`; the comparison-video
  renderer uses the same value, while mean-embedding appearance is a separate
  protocol. Original released Skyfall-GS references are the upstream authors'
  models, not this fork's Stage 1.

### Known boundary issues retained in this development snapshot

This publication preserves the current implementation rather than introducing
additional behavior changes during release preparation. The following code-review
findings are **not fixed** in this snapshot:

- The evaluator's dataset-provenance reader does not consume the archive worker's
  current `archive_status.json` / scene-level `dataset_checksums.json` schema.
  Its `input_data_compatible` flag alone is therefore not sufficient evidence that
  the current dataset bytes match the archived training inputs. Independently
  verify dataset digests before relying on evaluation or deletion clearance.
- The archiver's dataset digest cache uses file sizes for freshness and can miss
  same-sized input changes.
- Custom cleanup approval `requires` values are not rejected when the gate name
  is unrecognized. Do not use unrecognized approval gates; use the watcher's
  `--no-cleanup` option when automatic deletion is not required or approval
  configuration has not been independently checked.
- The archive scratch selector does not match the actual
  `idu/episode_*/geometry` and sibling directory depth. Legacy/noncompact
  episode scratch may remain on the source even after archival.
- Compact-retention replay can double-prefix persisted paths when the stage
  root is relative. Use absolute stage output roots for this snapshot.
- A failed requested video export can still be classified as a completed
  evaluation. Verify the requested video files independently; the separate
  single-video composer checks its actual output duration and assets.
- `transfer --verify-only` still checks source readiness before consulting the
  frozen manifest, so it can refuse after authorized remote-final cleanup.
  Local verification against the frozen archive manifest remains possible
  independently of that command.

These limits do not turn the partial experiment results above into a completed
full-dataset benchmark, and passing the existing test suite does not establish
that the listed boundary cases are covered.

### Validation for publication

- Existing suite: `python -m pytest -q tests` passed 96 tests. One
  dataset-dependent legacy JAX_214 test initially failed because its historical
  relative data path was absent. With a temporary link to the existing real
  JAX_214 dataset, that test passed separately (1 passed); no runtime or test
  implementation was changed to obtain the result.
- The committed MoGe patch matches the complete current two-file submodule
  diff byte-for-byte; reverse-apply context validation passed.
- The local-inference comparison workflow previously rendered all 13 available
  complete models. The six-scene final video is 84 seconds / 2,520 frames at
  1920x1080, 30 FPS, and passed full FFmpeg decoding. This is runtime evidence for
  that local environment, not a claim that the full 24-stage experiment or every
  deployment configuration has been validated.
